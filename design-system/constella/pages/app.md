# Page override: in-app screens (persona workspaces)

Skill row *Bauhaus* lists "do not use for data-heavy screens", so app screens use **Bauhaus Ops**:
- Same palette, type and primitives (as division icons), but 1px hairline borders, 0 radius cards, hard shadow only on the
  primary action card per screen.
- Density dial 7: 8–32px spacing scale; tables with right-aligned mono figures, no zebra stripes.
- Charts: division colours from MASTER, always with labels/legend (never colour alone).
- Transitions 150–250 ms; no custom cursor; skeletons for loading; toasts for actions.
